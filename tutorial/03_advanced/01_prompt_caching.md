# 01 — Prompt Caching

## Проблема

Уяви що в тебе є великий system prompt: 50-сторінковий документ, інструкції, few-shot приклади — 50k токенів. Кожен user-запит відправляє ці 50k токенів + питання. При 1000 запитів на день це 50 мільйонів input токенів тільки за system prompt. Дорого.

---

## Що таке prompt caching

Anthropic зберігає частину твого промпту в **KV-кеші** на своїх серверах. Наступний запит з ідентичним текстом — не перераховує, а читає з кешу. Читання кешу коштує **в 10 разів дешевше** ніж звичайний input.

**TTL кешу:** 5 хвилин. Якщо в ці 5 хвилин не було жодного звернення — кеш видаляється.

---

## Як використовувати

Додаєш `cache_control: { type: "ephemeral" }` до блоку який хочеш кешувати:

```ts
system: [
  {
    type: "text",
    text: VERY_LARGE_DOCUMENT,
    cache_control: { type: "ephemeral" }  // ← кешуй це
  }
]
```

---

## Перший запит — cache write, наступні — cache read

```
Запит 1:  cache_creation_input_tokens: 48000, cache_read_input_tokens: 0
Запит 2:  cache_creation_input_tokens: 0,     cache_read_input_tokens: 48000  ← ✓ хіт
Запит 3:  cache_creation_input_tokens: 0,     cache_read_input_tokens: 48000  ← ✓ хіт
```

Cache write трохи дорожче звичайного input ($3.75 vs $3 per million для sonnet), але вже з другого запиту ти в прибутку.

---

## Що можна кешувати

- System prompt
- Великі документи на початку conversation
- Few-shot приклади
- Tool definitions (якщо їх багато)

**Правило:** кешується все що **до** останнього `cache_control` блоку. Тобто кеш — це "префікс" промпту.

---

## Підводні камені

**1. Текст має бути побайтово ідентичним.**
Будь-яка зміна — один пробіл, інший регістр — промах кешу і нова cache write. Не динамізуй текст що має кешуватись.

**2. Модель теж має бути однаковою.**
Кеш прив'язаний до конкретної моделі. `claude-sonnet-4-6` і `claude-haiku-4-5-20251001` — різні кеші.

**3. 5-хвилинний TTL — для активних систем.**
Якщо запити приходять рідше ніж раз в 5 хвилин — кеш постійно протухає. В таких випадках вигода мінімальна.

**4. Мінімум ~1024 токени для кешування.**
Anthropic не кешує блоки менші за певний поріг (≈1024 токени). Кешувати маленькі тексти немає сенсу.
