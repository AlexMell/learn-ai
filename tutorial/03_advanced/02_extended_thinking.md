# 02 — Extended Thinking

## Що це

Extended thinking дає моделі "чернетку" де вона може міркувати перш ніж написати фінальну відповідь. Цей процес міркувань видно тобі, але не передається далі як частина відповіді.

Аналогія: людина спочатку думає в голові, потім говорить. Thinking tokens — це "думки в голові".

---

## Чому це працює

Стандартна модель генерує відповідь послідовно зліва-направо. При складних задачах це означає що вона "вирішує" і "пише" одночасно — немає можливості "передумати".

З thinking — спочатку ітеративне міркування (кілька тисяч токенів), потім фінальна відповідь вже з готовим планом. Якість на складних задачах суттєво вища.

---

## Як використовувати

```ts
{
  model: "claude-sonnet-4-6",  // haiku не підтримує
  max_tokens: 16_000,          // має бути достатньо для thinking + відповідь
  thinking: {
    type: "enabled",
    budget_tokens: 8_000       // скільки токенів дозволено витратити на думки
  },
  messages: [...]
}
```

`budget_tokens` — це **максимум** для thinking, не гарантія. Проста задача може використати менше.

**Вимога:** обов'язково стрімінг. Без нього — помилка.

---

## Структура стріму з thinking

```
content_block_start → { type: "thinking" }
content_block_delta → { type: "thinking_delta", thinking: "Let me analyze..." }
content_block_stop

content_block_start → { type: "text" }
content_block_delta → { type: "text_delta", text: "The answer is..." }
content_block_stop
```

Спочатку йде thinking блок (може бути великий), потім text блок з фінальною відповіддю.

---

## Коли використовувати

| Задача | Потрібен thinking? |
|---|---|
| Простий FAQ, переклад | Ні — зайві витрати |
| Складна математика, логіка | Так |
| Архітектурні рішення | Так |
| Дебагінг складного коду | Так |
| Генерація тексту | Зазвичай ні |

---

## Підводні камені

**1. Output tokens — це thinking + відповідь разом.**
`max_tokens: 16_000` — це ліміт на всі output токени разом. Якщо `budget_tokens: 15_000` і думки займуть 14k, для фінальної відповіді залишиться лише 2k. Завжди залишай запас.

**2. Thinking токени дорогі.**
Вони коштують як звичайні output токени. 10k thinking tokens на кожен запит — помітна сума.

**3. Не можна змішати thinking з prompt caching на одному блоці.**
Thinking блоки не можна кешувати через `cache_control`.

**4. Модель може "думати" довго навіть про прості речі.**
Якщо передаєш великий `budget_tokens` — модель може їх "витратити" навіть коли не потрібно. Підбирай бюджет під складність задачі.
