# 03 — Vision (зображення)

## Як модель "бачить" зображення

Claude — мультимодальна модель. Зображення конвертуються в токени спеціальним vision encoder'ом і обробляються разом з текстом в одному контексті.

Зображення теж **коштують токени**. Приблизно:
- Невелике зображення (до 1000x1000) ≈ 1000–2000 tokens
- Велике зображення може коштувати 4000+ tokens

---

## Два способи передати зображення

### 1. URL (простіше)
```ts
{
  type: "image",
  source: {
    type: "url",
    url: "https://example.com/image.png"
  }
}
```
Сервер Anthropic сам завантажує зображення за URL. Зображення **має бути публічно доступне**. Якщо URL потребує авторизації — не спрацює.

### 2. Base64 (для локальних файлів)
```ts
{
  type: "image",
  source: {
    type: "base64",
    media_type: "image/png",  // image/jpeg, image/gif, image/webp
    data: imageBuffer.toString("base64")
  }
}
```
Зображення кодується в base64 і передається в тілі запиту. Це збільшує розмір запиту (~33% overhead від base64 encoding).

---

## Структура content з зображенням

Коли є зображення — `content` у message це **масив** блоків, а не рядок:

```ts
messages: [{
  role: "user",
  content: [
    { type: "image", source: { ... } },
    { type: "text", text: "What do you see?" }
  ]
}]
```

Можна чергувати кілька зображень і текстів в довільному порядку.

---

## Підтримувані формати

| Формат | MIME type |
|---|---|
| PNG | `image/png` |
| JPEG | `image/jpeg` |
| GIF | `image/gif` |
| WebP | `image/webp` |

PDF і відео — не підтримуються через image API (є окремий files API для документів).

---

## Підводні камені

**1. Великі зображення — багато токенів.**
Якщо у тебе 10 скріншотів у запиті — може легко набігти 20-30k токенів тільки на зображення. Стискай зображення перед відправкою якщо деталі не критичні.

**2. URL кешується на боці Anthropic ненадовго.**
Не розраховуй що одне і те ж URL-зображення буде підтягнуто миттєво вдруге. В продакшені краще base64 або files API для стабільності.

**3. Claude добре бачить текст на зображеннях (OCR).**
Можна передавати скріншоти UI, PDF-сторінки, діаграми. Але для великих документів — files API ефективніше.

**4. Приватні зображення — тільки base64.**
Будь-який URL в запиті = Anthropic-сервер іде за цим URL. Якщо зображення з внутрішнього сховища або містить sensitive дані — передавай тільки base64.
