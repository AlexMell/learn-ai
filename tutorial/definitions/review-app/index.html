Prompt Eval Системний підхід

КрокДія
1. DefineЩо таке "правильна відповідь" для цієї задачі
2. CollectТест-сет: 20+ прикладів (100+ для надійності)
3. BaselineЗапусти поточний промпт — це точка відліку
4. IterateОдна зміна за раз → запускай на повному тест-сеті
5. CompareAccuracy / consistency / cost / format compliance
6. DeployТільки якщо новий кращий за baseline за головними метриками
7. MonitorРозподіл даних змінюється — потрібен ongoing eval
