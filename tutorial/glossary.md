# Glossary — терміни та абревіатури

## $

**$ARGUMENTS**
Змінна в Claude Code custom commands. Підставляє текст який ти передаєш після назви команди. Наприклад: `/doc-task 06_structured_output.ts` → `$ARGUMENTS` = `"06_structured_output.ts"`. Дозволяє робити команди гнучкими замість хардкодингу.

---

## A

**as const**
TypeScript-оператор який "звужує" тип літерала до конкретного значення замість загального. `type: "object" as const` → тип `"object"`, а не `string`. Потрібен коли TypeScript-інтерфейс вимагає точний literal type.

**API (Application Programming Interface)**
Інтерфейс через який програми спілкуються між собою. Claude API — це набір HTTP endpoints до яких ти відправляєш запити і отримуєш відповіді.

**Agentic loop**
Патерн де модель викликає tools кілька разів поки не дійде до фінальної відповіді. Цикл: запит → tool_use → виконати → передати результат → повторити до `end_turn`.

**Async / Await**
Синтаксис JavaScript для роботи з асинхронними операціями. `await` зупиняє виконання функції і чекає на результат (наприклад HTTP відповідь), не блокуючи весь процес.

---

## B

**BPE (Byte Pair Encoding)**
Алгоритм токенізації. Частові комбінації символів об'єднуються в один токен. "programming" → 1 токен, але слова з нелатинських алфавітів — кілька токенів.

**budget_tokens**
Параметр extended thinking — скільки токенів модель може витратити на "роздуми" перед фінальною відповіддю.

---

## C

**Custom slash commands (Claude Code)**
Власні команди які ти створюєш для Claude Code. Зберігаються як `.md` файли в `.claude/commands/<назва>.md`. Викликаються в чаті як `/<назва>`. Вміст файлу — це промпт який Claude виконує. Можна використовувати `$ARGUMENTS` для передачі параметрів. Бувають project-level (`.claude/commands/`) і user-level (`~/.claude/commands/`).



**cache_control**
Поле в запиті яке позначає блок для кешування на сервері Anthropic. Повторні запити з ідентичним текстом читають з кешу — в 10 разів дешевше.

**content[]**
Масив блоків у відповіді від Claude. Може містити `text` блоки і `tool_use` блоки. Завжди перевіряй `block.type` перед тим як читати поля.

**Context window**
Максимальна кількість токенів яку модель може обробити за раз — input + output разом. У Claude — 200k токенів.

---

## D

**dotenv**
npm пакет який читає `.env` файл і кладе змінні в `process.env`. `import "dotenv/config"` запускає це автоматично при імпорті.

---

## E

**end_turn**
Значення `stop_reason` — модель закінчила відповідь природньо. В agentic loop це сигнал виходити з циклу.

**env var (environment variable)**
Змінна середовища — спосіб передати конфігурацію (наприклад API ключ) без хардкодингу в коді. Зберігається в `.env` файлі локально.

**ESM (ECMAScript Modules)**
Стандарт модулів в JavaScript. `"type": "module"` в `package.json` вмикає ESM — тоді використовуєш `import/export` замість `require/module.exports`.

---

## F

**finalMessage()**
Метод стріму який чекає завершення і повертає повний об'єкт відповіді — з `usage`, `stop_reason` тощо.

**for await...of**
Синтаксис для читання async iterable (наприклад стріму). Кожна ітерація чекає на наступний елемент.

**Function calling**
Інша назва для tool use. Модель "викликає функцію" — насправді просто повертає JSON з назвою і аргументами, а ти виконуєш реальний код.

---

## H

**HTTP POST**
Тип HTTP запиту для відправки даних на сервер. Всі запити до Claude API — це POST на `api.anthropic.com/v1/messages`.

---

## I

**input_tokens**
Кількість токенів у твоєму запиті (system prompt + messages). Враховується в оплаті.

---

## J

**JSON Schema**
Стандарт для опису структури JSON об'єктів. Використовується в `input_schema` для tools — описує які поля очікуються, їх типи і які обов'язкові.

---

## K

**KV-cache (Key-Value cache)**
Серверний кеш на стороні Anthropic. При prompt caching — зберігає оброблені токени промпту. Повторний запит читає з кешу замість повторної обробки.

---

## L

**LLM (Large Language Model)**
Велика мовна модель. Нейронна мережа натренована на великих обсягах тексту. Claude, GPT-4, Gemini — це LLM. Генерує текст токен за токеном на основі ймовірностей.

**Latency**
Затримка — час між відправкою запиту і отриманням відповіді.

---

## M

**max_tokens**
Обов'язковий параметр — ліміт на кількість output токенів. Якщо модель досягає ліміту — відповідь обрізається, `stop_reason` стає `"max_tokens"`.

**MessageParam**
TypeScript тип з Anthropic SDK: `{ role: "user" | "assistant", content: string | ContentBlock[] }`.

**Multimodal**
Модель яка розуміє різні типи даних — текст, зображення. Claude — мультимодальна модель.

---

## O

**output_tokens**
Кількість токенів згенерованих моделлю у відповіді. Зазвичай дорожчі за input токени (~5x).

---

## P

**process.env**
Глобальний об'єкт в Node.js де зберігаються змінні середовища. `process.env.ANTHROPIC_API_KEY` — стандартне місце для API ключа.

**Prompt**
Вхідний текст який ти відправляєш моделі. Складається з system prompt + messages.

**Prompt caching**
Механізм збереження частини промпту на сервері. Повторні запити з тим самим текстом читають з кешу — дешевше і швидше.

---

## R

**REST API**
Архітектурний стиль для веб-сервісів на основі HTTP. Claude API — REST: HTTP методи (POST), JSON тіло, статус коди.

**role**
Поле в message — хто написав: `"user"` (ти / твій юзер) або `"assistant"` (Claude). Messages мають чергуватись.

---

## S

**Sampling**
Процес вибору наступного токена з розподілу ймовірностей. Контролюється через `temperature` і `top_p`.

**SDK (Software Development Kit)**
Бібліотека яка обгортає API і надає зручний інтерфейс. `@anthropic-ai/sdk` — офіційний SDK для Node.js/TypeScript.

**SSE (Server-Sent Events)**
Веб-протокол для однонаправленого потоку даних від сервера до клієнта по HTTP. Використовується під капотом при стрімінгу Claude.

**Stateless**
API не зберігає стан між запитами. Кожен запит незалежний. Claude API — stateless, тому ти сам зберігаєш і передаєш всю историю розмови.

**Structured output**
Патерн отримання гарантовано структурованих даних від LLM. Замість парсингу тексту — примусовий виклик tool через `tool_choice`, де `block.input` завжди містить валідний JSON потрібної форми. Усуває проблему варіативності текстових відповідей.

**stop_reason**
Пояснення чому модель зупинила генерацію: `end_turn`, `max_tokens`, `tool_use`, `stop_sequence`.

**stop_sequences**
Масив рядків при появі яких генерація зупиняється. Самі рядки не включаються у відповідь.

**Streaming**
Режим де токени відправляються клієнту по одному в реальному часі, не чекаючи повної відповіді.

**system prompt**
Окреме поле в запиті яке задає поведінку і контекст моделі для всієї розмови. Має вищий пріоритет ніж user повідомлення.

---

## T

**temperature**
Параметр семплінгу (0–1). 0 — детерміновано, завжди найімовірніший токен. 1 — максимальна варіативність.

**token**
Одиниця тексту якою оперує модель. Приблизно 4 символи або ¾ слова англійського тексту. Токени = одиниця оплати.

**tool_choice**
Параметр який контролює чи може Claude викликати tools: `"auto"` (сам вирішує), `"any"` (мусить викликати хоча б один), `{ type: "tool", name: "..." }` (конкретний tool).

**Type assertion**
TypeScript-синтаксис `value as SomeType` — каже компілятору "довір мені, я знаю точний тип цього значення". Обходить перевірку типів. Використовується для `block.input` (який завжди `unknown`) коли ти знаєш форму з `input_schema`.

**tool_result**
Тип блоку в user-повідомленні — результат виконання tool. Містить `tool_use_id` (прив'язка до виклику) і `content` (результат рядком).

**tool_use**
Тип блоку у відповіді Claude — запит на виклик інструменту. Містить `id`, `name` і `input` (аргументи).

**tool_use_id**
Унікальний ідентифікатор конкретного виклику tool. Потрібен щоб прив'язати `tool_result` до відповідного `tool_use` блоку.

**top_p (nucleus sampling)**
Параметр семплінгу — розглядати тільки токени чия сумарна ймовірність ≤ p. Anthropic рекомендує міняти або `temperature`, або `top_p`, не обидва.

**TTFT (Time To First Token)**
Час від відправки запиту до появи першого токена у стрімі. Важлива метрика для UX.

**tsx**
npm пакет який запускає TypeScript файли напряму без компіляції. `npx tsx file.ts` — те саме що `node file.js` але для TypeScript.

---

## U

**usage**
Об'єкт у відповіді з кількістю використаних токенів: `input_tokens`, `output_tokens`, і опціонально `cache_read_input_tokens`, `cache_creation_input_tokens`.

---

## X

**x-api-key**
HTTP заголовок для передачі API ключа. SDK додає його автоматично до кожного запиту.
